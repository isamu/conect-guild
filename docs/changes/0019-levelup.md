# #19 レベルアップの演出（2026-10-12）

Issue #19 の 3 本目。レベルが上がったときの演出を足した（DESIGN.md 4.4、4.6、4.8。社長の判断）。

- 差分の基準（localStorage）に各メンバーのレベル（数字だけ。王様は無し）を足し、基準の版を 2 → 3 に上げた。更新後の最初の 1 回は、古い基準が初回扱いになるので何も出ない
- イベント `level-up` を足した。初回・レベルが下がったときは出さない。2 つ以上上がっても 1 回にまとめ、上がった先のレベルを言う。同じ差分のクリア・宝箱のメッセージの後に置く
- 7 日より長い空白のあとも、レベルアップだけは出す（レベルは全履歴から数え直すので取りこぼさない。設計案のとおり）。halted から戻ったときは、止まる前の基準と比べて出す（クリアなどと同じ扱い）
- 効果音はオリジナルの楽譜 `levelup` を足した。クリアより長く、最後に一番高い音を伸ばす
- Canvas は、本人が席で 2 回跳ね、紙吹雪と「LEVEL UP」の文字（`fillText`）を出す。新しい絵は足さない。跳ねるのは描く位置だけにした。足元を動かすと、席の沈み込みが混ざって椅子から立ち上がるように見え、机との前後関係も変わるため（実装時の判断）
- 席にいないとき（遊びに出ている、ほかの演出の途中）は、本人を演出の配役にして、席に戻ってから跳ねる。メッセージもそれまで待つ。設計案（4 章）の「キューの配役待ちの仕組みがそのまま使える」に沿った。紙吹雪だけのクリアは配役を持たないが、跳ねる間は本人の動きを預かるため（実装時の判断）
- 統合レビュー（gpt-6-sol）の指摘で 2 つ直した
  - 遊びに出ている人のレベルアップで、メッセージと効果音が先に出て、帰り道のあとで跳ねていた。メッセージがキューに入った時点で本人を席へ戻し、キューは Canvas から受け取った戻るまでの時間だけ表示を待つようにした。Canvas とキューの間は、キューが持つ小さな口（`StageRecall`）で受け渡す。ほかの出来事の待ち方（#23）は変えていない
  - 呼びかけの返事「はっ！」が「LEVEL UP」の間に来ると、文字が吹き出しを覆っていた。返事の間は文字を吹き出しの上へずらした。返事そのものをやめる案もあったが、演出中の人もその場で返事をする 4.10 の規則に合わせた
- 紙吹雪が出ている間は、クリアと同じく壁の旗もはためく（紙吹雪を見て動く既存の仕組みのまま。実装時の判断）
- E2E を 1 本足した（サンプルの snapshot の履歴に完了を 2 件足すと、窓に「みのりは レベル 4 に あがった！」が出て、Canvas に「LEVEL UP」が描かれる。最初の読み込みでは出ない）
