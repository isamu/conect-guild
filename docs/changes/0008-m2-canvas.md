# #8 M2: Canvas の社屋（2026-10-12）

- **M2（2026-10-12）** Canvas の社屋を入れた
  - タイルを CC0 素材から codex 生成に変えた（8 章、10 章 3。社長の判断）
  - 論理解像度を 1024×576（32px タイル）にした（6 章。社長の判断で 2 倍に）。キャラのコマは 64px で始め、同日に原画の比率に合わせて 80px にした
  - render/ の中身を書いた（3 章）
  - 出来事が無い間の小さな動き（アンビエント）を足した。状態だけで決め、新しいデータや絵は足さない（3 章。社長の要望）
  - 部屋を原画の比率で作り直した: 家具を大きくし、キャラを 80px にし、小物で埋めた。灯りの火とネコの寝息はアンビエントで動かす（6 章、8 章。社長の判断）
  - 席は右の窓の最大の伸び（取得状況の通知が重なったとき 373px）にもかからない位置にした。歩ける判定は通常の高さ（340px）のまま（3 章 map.ts）
  - 演出を「部屋から出て出かける」から「かなめが仲介する」に改めた。実際の部門セッションは机で作業するので、出かける演出はパーティの窓の「作業中」と食い違い、意味が伝わりにくかった（1 章、4.4、6 章。社長の判断）
  - メッセージの切り替えを演出に合わせた: 受け渡しは 10〜14 秒かかり、8 秒ごとのメッセージと並べると、かなめの出来事が続いたときに演出がメッセージから遅れていた。次のメッセージは配役が空くまで待つ。ページが非表示の間はメッセージも止める。▼ は予約にし、狭い画面で Canvas が隠れている間の演出は捨てる（6 章 M2）
  - 閉じ直しの判定を「基準の closedAt より後」に改めた。基準の fetchedAt より新しい closedAt の Issue が取得のたびにクリアを出していた。closedAt が古い値に変わっただけでは閉じ直しにしない（4.4 の実装の修正）
