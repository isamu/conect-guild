# #54 変更履歴を Issue ごとのファイルに分けて、PR どうしの衝突をなくす（2026-10-12）

- **Issue #54（2026-10-12）** DESIGN.md の「変更履歴」を `docs/changes/` の Issue ごとのファイルに分け、過去の分も文言を変えずに移した。DESIGN.md の節は案内だけにした（社長の判断）
  - 並行する PR がどれも節の先頭の同じ位置に 1 行を足すため、2 本目以降がかならず衝突していた（2026-10-12 の衝突のうち、コードの衝突は 1 回だけだった）
  - Issue の無い過去の項目は PR 番号でファイル名を付けた（`pr-0002-design-review.md`、`pr-0031-toy-poodle.md`）。決まりは `docs/changes/README.md` に書いた
  - PR 本文に「マージの順番」を書くことにした。ブランチを数珠つなぎにするのは、コードが重なる PR どうしだけにする（CLAUDE.md）
